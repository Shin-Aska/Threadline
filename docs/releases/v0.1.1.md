Threadline v0.1.1 expands the desktop workspace for Bluesky and Mastodon.

- Browse provider-backed profiles, threads, tags, followed people, lists, feeds, discovery, and notifications from one workspace.
- Preserve workspace navigation and loaded presentation state as you move between responsive source views and details.
- Use account-scoped likes, reposts, replies, and follows, with a selected account for each action.
- Reuse account-scoped social data, batch Bluesky notification reads, and pause inactive workspace polling.
- Keep drafts, publication history, media, and local schedules in the desktop app’s SQLite data directory.
- Publish cross-posts with destination results, thread splitting, image and MP4 video support, and provider-aware limits.
- Connect Mastodon through browser OAuth with PKCE, or use stored credentials for either provider. Bluesky supports app-password connections and browser OAuth where its client configuration is available.

### Downloads

Choose `linux-x86_64` (AppImage or Debian package), `windows-x86_64` (EXE or MSI), or the macOS DMG for Apple Silicon (`aarch64`) or Intel (`x86_64`).

These installers are built by GitHub Actions and include SHA-256 checksums and build provenance attestations. Verify a downloaded installer with:

```bash
gh attestation verify ./YOUR_DOWNLOADED_FILE --repo Shin-Aska/Threadline \
  --signer-workflow Shin-Aska/Threadline/.github/workflows/release.yml \
  --source-ref refs/tags/v0.1.1 --deny-self-hosted-runners
```

Windows installers are not publisher-signed, and macOS builds are not Apple-notarized. OS security prompts may appear. GitHub provenance verification does not replace platform code signing.

### Current limits

Scheduling runs only while this desktop app is open. A missed schedule or one that resumes more than one minute late is marked for review instead of sending late. Provider availability, media limits, and remote outcomes remain provider-dependent.

Packaged Bluesky browser OAuth requires a publicly hosted HTTPS client-metadata document and a registered native callback. This checkout does not host or live-verify that configuration, so packaged Bluesky browser sign-in may be unavailable; use the app-password fallback in that case.
