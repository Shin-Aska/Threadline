Threadline’s first desktop release for Bluesky and Mastodon.

- Combined home timelines with account filters and source attribution.
- A redesigned Composer with destination selection and per-network previews.
- Cross-posting with three thread-splitting policies, image attachments, and alt text.
- Hashtag suggestions and per-account publication results.
- Local account management using the operating system credential store.

### Downloads

Choose `linux-x86_64` (AppImage or Debian package), `windows-x86_64` (EXE or MSI), or the macOS DMG for Apple Silicon (`aarch64`) or Intel (`x86_64`).

These installers are built by GitHub Actions and include SHA-256 checksums and build provenance attestations. Verify a downloaded installer with:

```bash
gh attestation verify ./YOUR_DOWNLOADED_FILE --repo Shin-Aska/Threadline \
  --signer-workflow Shin-Aska/Threadline/.github/workflows/release.yml \
  --source-ref refs/heads/main --deny-self-hosted-runners
```

Windows installers are not publisher-signed, and macOS builds are not Apple-notarized. OS security prompts may appear. GitHub provenance verification does not replace platform code signing.

### Current limits

Drafts and publication results are not saved across restarts. Discover and Following have partial provider support. OAuth sign-in, scheduling, notifications, video, and in-app reactions are not implemented.
