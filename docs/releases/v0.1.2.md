Threadline v0.1.2 improves Linux package compatibility and bounds long-running social browsing state.

## Highlights

- Fixes AppImage startup failures on newer Linux distributions by keeping host GLib/GIO and nghttp2 ABI families coherent instead of mixing them with Ubuntu 22.04 copies.
- Bundles a complete, controlled GStreamer runtime through Tauri's supported media-framework integration, including `autoaudiosink` discovery.
- Adds extracted-library auditing and packaged startup smoke tests on Ubuntu 22.04 and Ubuntu 24.04, plus a repeatable Kubuntu validation script.
- Adds a configurable in-memory provider-response post budget (Off, 50, 100, 250, or 500; default 250), with LRU eviction and safe preference fallback.
- Bounds mounted feed and notification post retention to 500 post-bearing rows per retained view while preserving navigation, filters, account isolation, and scroll restoration.

## Linux runtime notes

The AppImage uses the target distribution's GLib/GObject/GIO and nghttp2 libraries so distribution GIO modules and curl stay ABI-compatible. Audio/video plugins are bundled as one GStreamer set. The Debian package recommends the runtime-only `gstreamer1.0-plugins-good` and `gstreamer1.0-pulseaudio` packages.

KDE GTK theme-module warnings can remain cosmetic. Loader `undefined symbol` failures, incompatible dconf/libproxy modules, a missing `autoaudiosink`, and GLib-GObject criticals are regression-test failures.
